# OpenDesign Agent Guidelines (Windows Native)

1. **Aesthetics & Premium Design**: Apply Tailwind CSS with curated dark mode palettes, rounded containers, high contrast typography, and subtle micro-animations.
2. **Windows Compatibility**: Use PowerShell / Node.js natively. No bash-only or macOS tools.
3. **Component Isolation**: Maintain clean state boundaries using React sub-components.
