# Carpeta de Imágenes Públicas (`public/images/`)

Guarda aquí los elementos gráficos (logos, escudos, firmas, sellos, marcas de agua) que quieras usar directamente en la aplicación.

## Referencia en el código:
- En HTML/JSX: `<img src="/images/tu-imagen.png" alt="Descripción" />`
- En CSS/Tailwind: `background-image: url('/images/tu-imagen.png');`
